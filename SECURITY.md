# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| 1.0.x | :white_check_mark: |
| < 1.0.0 | :x: |

## Reporting a Vulnerability

VeloxGrid TV is completely sandboxed, requests no internet access, and collects no external telemetry. However, if you discover an issue with intent sanitization or activity task handling:

1. **Do not create a public issue.**
2. Open a private security advisory through the repository's **Security** tab or contact the maintainer directly.
3. Provide the device brand, chipset model, Android OS version, and steps to reproduce.
